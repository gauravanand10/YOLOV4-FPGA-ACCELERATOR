# 05_tb — verification: bit-exact testbench, AXI memory model, gate-level flow

**Method.** The testbench loads a complete DDR image produced by the golden model. It then runs the
accelerator exactly as the ARM will (through AXI-Lite) and compares **every 128-bit word of DDR**
against the image the golden descriptor simulator (`02_golden_model/hwprog.simulate`) produced. A single
wrong bit anywhere (outputs, intermediate feature maps, or a stray write outside a buffer) fails the test.

## Files

| File | What it is |
|---|---|
| `tb_top.sv` | Top testbench. 200 MHz clock. AXI-Lite master tasks. `$readmemh` of `mem_init.hex`/`mem_exp.hex`. Programs DESC_ADDR/NUM_LAYERS, starts, polls STATUS.done. Prints per-layer cycles, the register counters and AXI statistics. Compares the whole memory. Can run back-to-back (`RUNS`). |
| `axi_mem_model.sv` | AXI4 slave memory (128-bit, up to 16 MiB). In-order reads with programmable AR→R latency. Random throttling of ready/valid on every channel (`STALL` %). **Protocol checker:** INCR only, 16-byte size, len ≤ 63, no 4 KiB crossing, correct WLAST, W never before its AW, address in range. |
| `files.f` / `files_sim.f` | Compile order: RTL (package first), then the testbench |
| `run_xsim.bat` | Compile + elaborate + run with Vivado xsim, then report PASS/FAIL |
| `data/feature/` | 11-layer random test (about 29k words), generated by `03_quant_export/export.py` |
| `data/yolo/` | Full 416×416 network on `000000000074.jpg` (948,224 words); `input_rgb.npy` is the image |
| `gatesim/` | Post-synthesis (gate-level) functional simulation flow, described below |
| `sim/` | xsim work directory (generated; safe to delete) |

Each `data/<test>/` folder contains `test.cfg` (`base desc_addr num_layers words`), `mem_init.hex`,
`mem_exp.hex` and `regions.txt` (where each buffer lives, for debugging).

## Plusargs
| Plusarg | Default | Meaning |
|---|---|---|
| `+DATA=<dir>` | `data/feature` | test data folder |
| `+STALL=<pct>` | 0 | % of cycles each AXI channel is randomly throttled |
| `+LAT=<n>` | 40 | read latency AR → first R beat (cycles) |
| `+RUNS=<n>` | 1 | run the whole program n times back-to-back (re-start without reset) |
| `+MAXCYC=<n>` | 50 M | timeout |

## Run (Windows, Vivado 2024.1 at `C:\Xilinx`)
```bat
run_xsim.bat [test=feature|yolo] [stall%=0] [latency=40] [runs=1] [nocompile]

run_xsim.bat feature 30 3 2      & rem ~20 s
run_xsim.bat yolo 0 40 1         & rem ~16-60 min (full network, 7.5 M cycles)
```
Logs go to `D:\MPSOC_YOLO\logs\xsim_<test>.log`. The script ends with `PASS <test>` or `FAIL <test>`.

## What the feature test covers
Stride 1 and 2 · 3×3 and 1×1 · odd image sizes · 2×2 maxpool in the loader, with pooled rows > 8
slots · group split (channel offset) · concat into a wider buffer · dual destination · 2× upsample ·
36→64 head padding · kkcc = 288 (deepest weight bank use) · 1024-beat rows · 96-byte pixel stride so
pixels straddle 4 KiB pages · 27-bit bias saturation (both signs) · int8 output saturation · mixed
leaky/linear channels.

## Results (logs in `../logs/`)

| Run | Result |
|---|---|
| feature, 0 % stall, lat 1 / 3 / 40 / 100 | **PASS**, 28,928 words bit-exact |
| feature, 20 % / 30 % / 50 % stall, 2 back-to-back runs | **PASS**, 0 protocol errors |
| feature with a deliberately corrupted expectation (`xsim_feature_neg.log`) | **FAIL detected** (the checker works) |
| **yolo (full network), lat 40** | **PASS: 948,224 words bit-exact**, 7,481,892 cycles, 0 AXI protocol errors |
| gate-level feature test (`gatesim_feature.log`) | **PASS**, bit-exact, same bursts and beats as RTL |

Full-network statistics: 76,116 read bursts / 2,492,436 read beats, 200,434 write bursts / 400,868 write
beats, 136,188 row-wait cycles, 0 output-credit stalls, 376,860 weight-load cycles. That is 39.9 ms per
frame, **25.1 fps at 187.5 MHz**, within 1–3 % per layer of `02_golden_model/perf_model.py`.

## gatesim/ — post-synthesis functional simulation
Proves that synthesis did not change the behaviour (nothing trimmed, attributes honoured).

| File | Role |
|---|---|
| `run_gatesim.bat [test] [stall] [lat] [runs] [nosynth]` | the whole flow |
| `ooc_synth.tcl` | out-of-context synthesis of `yolo_accel_wrap`, then `write_verilog -mode funcsim` → `yolo_accel_wrap_funcsim.v` (41 MB) |
| `make_tb_gate.py` | generates `tb_top_gate.sv`: a copy of `tb_top.sv` without the RTL-internal progress monitor, that waits for the 100 ns global reset |
| `netlist_check.tcl` | checks the netlist hierarchy and cell counts |
| `ooc_utilization_hier.rpt` | OOC utilization (21,271 FF, 11,136 in `pe_array`; same BRAM/DSP as in-system) |
| `files_gate.f` | compile list with UNISIM models |

Result: `TEST PASSED: 28928 words bit-exact` in 56,405 cycles (RTL: 56,409; the 4-cycle difference is
the memory model's random write-response timing). Runtime is about 85 min.
